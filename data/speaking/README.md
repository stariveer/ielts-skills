# 口语素材库说明与 5 大万能故事体系

雅思口语 Part 2 的核心策略是用 **5 个万能故事覆盖 80% 以上的考题**。
请将各万能故事沉淀在当前目录：

1. `story_1_travel.md`：一次旅行 / 难忘地点 / 经历
2. `story_2_person.md`：一个重要的人物（老师/朋友/榜样）
3. `story_3_item.md`：一件物品 / 学会的技能 / 有用的工具
4. `story_4_event.md`：一次挑战 / 改变想法的经历 / 难忘事件
5. `story_5_media.md`：一本书 / 电影 / 影视作品 / 新闻

当使用 `/ielts-speaking` 时，AI 将自动调用或更新本目录中的故事，便于随时背诵与演练。
